## Review correction round 1

Scope is exactly the four Important findings in task-1-review.md; no domain functionality added.

1. **Commit before response:** exported `app.api.dependencies.Database = Annotated[Session, Depends(get_db, scope='function')]`. Every direct and transitive DB consumer now uses it, retaining one cached transaction. Regression injects SQLAlchemy before_commit failure in real-PG HTTP login and command requests: response is 500, no success cookie/token/body is emitted, failed sessions/commands do not persist. Additional route-tree assertion enforces function scope for every DB dependency. Future routers must declare `db: Database`, never bare Depends(get_db).
2. **Password fingerprint:** selected the review's strong costly-verifier alternative, not HMAC. All command fingerprints now use explicit `argon2id-sha256-v1:` plus salted Argon2id over the canonical payload digest; the fast intermediate digest is not persisted. Password create and reset retain same-body replay and reject changed-secret body with the same key. No additional secret/key lifecycle is introduced. Revision `a028a4baee91` changes request_hash to TEXT and cost-hashes old SHA256 values without knowing passwords or changing results. A legacy-command migration/retry test passes. Downgrade refuses nonempty command history rather than discarding commands or recreating weak verifiers. Already existing historical backups remain sensitive; a live migration does not retroactively rewrite them.
3. **Strict private ACL:** consolidated runtime/app protection into app.private_storage. New Windows security descriptors replace all existing inherited AND explicit grants for the root and existing descendants; only the operating account has FullControl. Each descriptor is re-read and validated. Reparse points and inability to apply/validate policy fail startup. Runtime protects before writing credentials. Isolated real-Windows test adds Everyone read to the root, child directory and file, then verifies its removal everywhere. Initial PowerShell security-module autoload was unavailable in this host context; implementation and test use built-in .NET ACL methods instead. The previous helper was rerun against that corrected test and fails specifically with `Extra principal`; current helper passes. No claimed support was inferred from an unsupported OS call.
4. **Atomic attachments:** write to a unique private temporary file, flush/fsync and checksum it, close it, then publish with an atomic same-filesystem hard link that never overwrites another complete winner. Each invocation removes only its own temporary path. Deterministic regression holds the first writer after partial bytes while a second writer uploads identical bytes; both complete and retain separate metadata rows. Interrupted write leaves no final object, cleans its temporary, and retry succeeds. Existing originals and unrelated files are not deleted. Hard-link support is required and failures are closed.
