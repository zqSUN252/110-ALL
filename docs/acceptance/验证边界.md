# 验证边界与诊断事件

本机程序回归、合成业务链、规模负载、用户包内快照回填与当前生产/真实外部渠道验收是不同证据。逐项范围见《实现与证据.json》，运行统计见《运行验证.json》；源码 ZIP 不包含业务备份或登录凭据。

2026-11-05 的一次诊断检索错误地把 `rg` 正文搜索范围扩展到私有目录，命中单行备份记录，工具返回在截断前包含真实业务片段。可见数据类别包括联系人、电话号码、地址和来源记录；没有在此记录复制任何原始片段。因未对完整工具转录进行独立秘密审计，不能断言没有凭据或会话相关内容进入工具转录。该事件属于开发工具输出边界失误，不能声称全过程零业务 payload 输出。

发现后停止私有正文的广泛检索，改用准确路径、文件名发现或内存解析后的白名单统计。保留原诊断证据，不为隐藏事件删除日志。该检索没有修改业务数据，也没有把业务记录写入源码或交付包；后两项仍以明确打包清单及内存秘密比对的实际检查结果为依据。产品服务关闭普通访问日志及其请求查询值，与本次工具输出事件分别记录。

自动审批另曾拒绝停止/重启一个旧合成测试进程，返回原因仅为 `blocked by policy`。该进程被保留，此后没有通过其他工具或命令重试终止；新验证使用其他自有端口和隔离 schema。后台进程不会自动注册为 Windows 服务或开机任务。

缺失原宣传图、精确模板截图、当前生产备份、真实 OCR 准确率、账号配对与投递、外部客户端粘贴、物理打印及正式 HTTPS 的条件仍未验收。测试用外部运输替身仅证明本机挑战/会话/范围控制流程，不证明真实通道可达。
